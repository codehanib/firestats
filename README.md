# 프로젝트
R studio를 이용한 빅데이터 분석 파일럿 프로젝트

## 프로젝트 소개
공공 데이터 포털( https://www.data.go.kr/ ) 의 산림청 제공 전국 산불 통계 csv 파일을
R studio로 정제, 분석, 시각화 하는 프로젝트입니다.

## 활용 기술, 프로그램
- R studio

## 프로젝트 목표
- 공공기관에서 제공하는 산불 통계 데이터 수집
- 2022년 ~ 2025년의 산불 발생 현황 분석
- 산불 피해 면적 및 발생 원인 분석
- 원 그래프, 막대 그래프 등을 통한 시각화 제공

## 기대 효과
- 산불 발생 현황을 시각화 자료를 통해 직관적으로 파악하고 산불 위험 지역 및 발생 패턴을 분석하여
   예방 정책 및 대응 전략 수립에 활용 가능한 데이터가 제공 가능하다.
- 실무형 프로젝트로 데이터 분석 및 시각화 경험을 쌓을 수 있다.
